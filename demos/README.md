# Bullock Digital Studios · Prospect Demo Organization

This public folder contains **unofficial, independently created website design previews**. These are not endorsements or live customer websites.

## Stable public demo paths
Keep each demo at `/demos/<business-slug>/` throughout the sales cycle. **Do not move directories as a lead progresses**, because links already sent to owners would break.

## Private sales pipeline (not stored in this public repo)
Track each prospect in a PRIVATE CRM or pipeline ledger with:
- Business name and slug
- Contact and decision-maker details
- Research and social/website references
- Sales status: New Prospect / Interested-Follow-up / Sold-Client / Archived-Declined
- Last contact, follow-up due date, next action
- PDF quote version, amount, and date
- Demo URL, deployment verification, and file links
- Decision and archive reason

Avoid storing private contact notes or unpublished quotes in this public repository.

## Lifecycle
1. **New Prospect**: research the business, create an individualized HTML demo and quote, test a shareable preview, email executive summary and quotation PDFs to the BDS owner.
2. **Interested / Follow-up**: preserve existing demo URL. Track feedback and revision requirements in a private sales record.
3. **Sold / Client Project**: migrate the approved website to a dedicated client repository and distinct Render service and domain. Continue to keep the former demo URL as a controlled preview or redirect after the owner approves it.
4. **Archived / Declined**: archive internal materials and mark the lead inactive. Retire public demo hosting after a sensible retention period and a check for shared links. Keep reusable code privately.

## Website safety
Every concept demo must say it's unofficial. Do not make working purchasing forms or imply authorization, endorsement, or verified operating details. No paid Render resources or external third-party services without explicit approval.
